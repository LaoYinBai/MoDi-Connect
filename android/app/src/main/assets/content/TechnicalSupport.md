# 技术支持

## 版本与更新

墨堤应用层核心源码按 GPLv3 开源。社区版不包含官方国内自动更新工具，可通过 [GitHub](https://github.com/LaoYinBai/MoDi-Connect) 或 [官网](https://modiconnect.cn) 获取发行信息。

更新安装请使用相同包名、相同签名且构建号不低于当前安装的 APK，不要为了升级先卸载应用，以免丢失本地数据。

## 连接排查

遇到连接问题时，请依次确认以下项目：

1. 手机与电脑选择了相同的链路方式。
2. 局域网模式下，两台设备处于可互通的网络中。
3. 电脑防火墙允许音频端口 12345 与握手端口 12347。
4. 使用虚拟麦克风路线时，目标软件选择了 CABLE Output 作为输入设备。
5. 在“设置 → 网络诊断”查看当前网络、目标与活跃链路；蓝牙需支持硬件与附近设备权限，USB 需数据线、USB 调试及电脑授权。

## 日志与诊断

如需提交问题，可先在“设置 → 调试 → 日志导出”导出诊断信息。请同时说明两端版本、目标链路、复现步骤和发生时间，不要发送配对凭据或未经脱敏的原始日志。
