# 技术支持

## 版本、获取与支持

墨堤应用层核心源码始终在 [GitHub](https://github.com/LaoYinBai/MoDi-Connect) 按 GPLv3 开源。社区版可从 [墨堤官网](https://modiconnect.cn) 或 GitHub Releases 获取，不包含官方国内自动更新工具。

官方打包、国内更新服务与持续维护通过 [墨堤爱发电主页](https://ifdian.net/a/modiconnect) 提供，不额外解锁核心功能。覆盖安装必须保持相同包名与签名、使用更高 Build；不要为了升级先卸载应用，以免丢失本地数据。

## 连接排查

1. 手机与电脑选择相同链路；优先使用 LAN 或 Wi-Fi Direct。
2. LAN 下两台设备应处于可互通网络，访客网络或 AP 隔离会阻止发现。
3. 电脑防火墙需允许音频端口 12345 与握手端口 12347。
4. 使用虚拟麦克风路线时，目标软件选择 CABLE Output 作为输入设备。
5. 在“设置 → 网络诊断”核对目标、活跃链路和真实状态，不要只凭动画判断已连接。

### USB 应急链路

USB 是 LAN 与 Wi-Fi Direct 不可用时的应急链路。Windows 包只运行随包提供的私有 ADB，不搜索系统 PATH、不安装全局 ADB，也不会停止系统 ADB。

1. 在手机“设置 → 关于手机”连续点击版本号，开启开发者选项。
2. 进入“系统/更多设置 → 开发者选项”，开启“USB 调试”。
3. 解锁手机，使用可靠 USB 端口和支持数据传输的线缆；若 USB 用途显示“仅充电”，改为“传输文件/Android Auto”等数据模式。Windows 完全不识别手机时，只安装手机厂商或 Windows Update 提供的驱动。
4. 首次连接、换电脑或墨堤私有授权密钥更新后，在手机“允许 USB 调试”RSA 窗口核对并只允许可信电脑，再回到墨堤选择 USB。`unauthorized` 表示尚未授权，`offline` 表示连接已中断。
5. 若 Android Studio、手机助手或系统 ADB 正在占用设备，请先退出相关工具并重新插线。转发失败或超时可返回 LAN/Direct，不要盲目卸载全部驱动或结束所有 ADB。用完后可关闭 USB 调试或撤销授权；该情况不会影响其他链路或应用启动。

## 日志与诊断

在“设置 → 调试 → 日志导出”导出诊断信息。提交问题时请说明两端版本、Build、目标链路、复现步骤和发生时间；不要发送配对凭据、密钥或未经脱敏的原始日志。
