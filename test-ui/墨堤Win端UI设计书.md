## 卷四 · 状态机与链路

### 4.1 连接状态机

| 状态 | 状态灯 | 男孩 | 水 |
|---|---|---|---|
| 未连接 | 🔴 朱砂 | 左岸待机（东张西望） | 无水 |
| 握手中 | 🟡 | 待机 / 行走中 | 无水 |
| 已连接 | 🟢 | 右岸站立 | 满水，RMS 调制 |
| 重连缓冲 | 🟡 | 倒放→待机 | 退水 |

### 4.2 四链路职责表

| 链路 | Win 端职责 | UI 体现 |
|---|---|---|
| **LAN** | mDNS 自动发现，**默认同意握手**，零操作 | 无专属控件，状态灯直接变绿 |
| **WiFi Direct P2P** | 右上角 QR 圆钮 + 左上角设备列表 | 见 4.3 / 4.4 |
| **蓝牙** | 手机端引导用户设置，Win 端本轮不做 | 无 |
| **USB** | 手机端引导用户设置，Win 端本轮不做 | 无 |

> 四链路同时监听；链路身份由握手包名决定，**UI 只读显示**。

### 4.3 P2P 双阶段流程（本版本打磨重点）

**初次配对（生客 · QR 码）：**
```
hover QR 圆钮 → 二维码以按钮为顶角弹出（UI 层有效期 2 分钟）
→ 手机扫码 → 状态灯 红→黄 → 握手 → M1 全套 → 绿
→ 握手被检测瞬间 QR 自动收起（它的任务完成了）
→ 设备写入列表

```

**回访（熟客 · 免扫码直连）：**
```
点击设备圆钮 → 弹层「P2P 已配对设备」→ 点击设备行
→ 状态灯 黄 → 后台握手（驱动自动完成，免扫码）→ M1 全套 → 绿

```

**QR 过期机制（防御性设计）：**
- 应用层的码实际不过期，但判定有 bug 风险 → **UI 层强制 2 分钟过期**
- 过期表现：二维码置灰 + 覆盖层"已过期 · 点击刷新"（300ms 淡入）
- 点击 QR 圆钮 = 重新生成新码

**连接失败（两种入口共用）：**
- 黄灯超时 → 红灯 → **系统级 Toast**（Windows 原生通知）："连接失败，请重试"

### 4.4 P2P 设备列表（专属组件）

- **仅服务 P2P 链路**——LAN/蓝牙/USB 无此概念；设计动机：宿舍 AP 隔离环境下 mDNS 失效，列表是唯一的"老朋友通道"
- 触发：主舞台左上角圆钮，图标 = **简笔画小手机**（暂定，可单独改）
- 弹层标题：「P2P 已配对设备」
- 每行：设备名 + 链路图标 + 上次连接时间（仿宋 12px），**整行可点直连**
- 最多显示 4 行，超出滚动（6px 细滚动条）
- 底部固定行：「+ 添加新设备」
- 空列表态：霞鹜文楷"还没有设备 · 悬停右上角圆钮扫码配对" + 指向 QR 圆钮的小箭头

## 卷五 · 动效宪法（全软件毫秒级唯一真源）

### 5.1 M1 · 连接仪式时间轴

**正放（连接建立，全程 2680ms）：**

```
握手成功（状态机已绿，仪式开始）
  ├─ 0ms          状态灯：红 → 黄
  ├─ 0–1200ms     男孩从左岸走向右岸
  │               12~16 步，每步 Y 轴微弹 ±2px，手臂简笔画式摆动
  │               步频 ease-in-out（起步慢、中段快、到岸收）
  │               ⚠ 行走全程保持灰色——还是灰世界
  ├─ 1200–1280ms  踏上右岸，脚步一顿（80ms 微停）
  ├─ 1280–1880ms  M2 墨晕上色（600ms）
  │               暖橘从男孩身上洇开 · 青绿从桥面洇开
  │               两色同时、不同源、各自扩散、交汇自然混合
  ├─ 1680ms       状态灯：黄 → 绿（上色 2/3 处转绿，不抢戏）
  ├─ 1880–2680ms  桥下涨水（800ms）
  │               从下到上位移 + 淡入，水面由平静起步
  │               ⚠ 此阶段音频尚未接入，水是"安静的"
  └─ 2680ms       仪式完成 → 音频调制无缝接入
                  男孩立于右岸面朝河水，水面开始随 RMS 呼吸

```

**倒放（断线，全程 2600ms）：**

```
断线事件进入队列（若正放未完，先等正放播完）
  ├─ 0–800ms      水退：从上到下位移 + 淡出，音频调制同步断开
  ├─ 800–1400ms   颜色褪回灰（M2 倒放，从边缘向源点收拢）
  ├─ 1400–2600ms  男孩走回左岸
  │               ⚠ A1 镜像规则：以 Y 轴镜像，男孩面朝左，
  │               步态正放（绝不倒着走），步频均匀、不弹跳——离场是安静的
  └─ 2600ms       恢复待机态
                  状态灯：绿 → 黄（缓冲期）→ 超时 → 红

```

### 5.2 M2 · 墨晕语法

| 参数 | 值 |
|---|---|
| 扩散形状 | 从源点径向扩散，**边缘羽化**（墨入水的毛边，非硬圆） |
| 局部晕（男孩/桥上色、连接仪式） | 600ms |
| 全局晕（深↔浅主题切换，从按钮至窗口四角） | 800ms |
| 缓动 | `EasingStandard` = `cubic-bezier(0.4, 0, 0.2, 1)` |
| 双色叠加 | 各自独立扩散，交汇自然混合，不互相遮挡 |
| 倒放 | 从边缘向源点收拢，时长同正放 |
| **适用边界** | **仅当切换两端都属于 {深色, 浅色} 时行墨晕礼；任何一端是自定义主题 → 降级为 300ms 普通淡入淡出。** 连接仪式的暖橘/青绿墨晕不受此限（那不是主题，是生命体征） |

### 5.3 M3 · 仪式优先（队列规则）

> M1 动画不可被打断。真实连接先于动画完成时，音频响应在队列外等候——先把桥走完、把水放满，河才开始流声音。动画进行中的状态变更一律排队。

| 情形 | 处理 |
|---|---|
| 握手成功时倒放未完 | 倒放播完 → 立即播正放 |
| 断线时正放未完 | 正放播完 → 立即播倒放 |
| 音频流在仪式中已建立 | 水面平静流淌，2680ms 处无缝接入调制 |
| 快速断连重连（<5s） | 正放→倒放→正放完整执行，**不合并——仪式不打折** |

### 5.4 A1 · 镜像规则

> 角色反向移动 = Y 轴镜像 + 步态正放。男孩是独立图层（L3），过桥时面朝右，回家时镜像为面朝左，脚步永远向前。全软件唯一的"倒放"只允许发生在水和颜色上，**永不发生在角色步态上**。

### 5.5 水流参数

| 参数 | 值 |
|---|---|
| 颜色 | `WaterBlue` `#86BFD8`，透明度 70%，带微光高光 |
| 横向流动 | 波纹左→右，约 40px/s，2~3 层不同频率正弦叠加 |
| 涨水 | 从下到上位移 + 淡入，800ms（M1 正放 1880–2680ms） |
| 退水 | 从上到下位移 + 淡出，800ms（M1 倒放 0–800ms） |
| 音频调制 | 波形振幅 × 音频 RMS：静音时近乎平镜，鼓点来时波峰翻涌 |
| 调制接入 | 正放 2680ms 处无缝接入；倒放开始时立即断开 |
| 自定义图片背景时 | 水流、桥、男孩保留；**背景纹理层自动关闭** |

### 5.6 男孩三件套

**① 待机 · 东张西望（主舞台左岸，灰色 = `TextSecondary`）**
- 4~6s 无缝循环：头左转 → 停 1s → 回正 → 停 0.5s → 头右转 → 停 1s → 回正
- 身体 2px 呼吸起伏，3s 周期

**② 过桥 · 行走（M1 专用）**
- 12~16 步，每步微弹 ±2px，手臂摆动，步频 ease-in-out
- 行走全程灰色，**踏岸瞬间才触发 M2 上色**——"先到了，再活过来"
- 倒放回程：镜像 + 步态正放 + 不弹跳不摆臂

**③ 钓鱼 · 关于页底（古代小木码头，戴斗笠）**
- 码头形制：古代小型木质码头，可停靠钓翁小木船
- 坐姿，双腿悬空 2s 周期微晃；鱼竿线垂入水中，浮漂微小起伏
- 每 15~20s 随机：浮漂一沉 → 鱼竿微弯 → 身体前倾 → 顿一下 → 恢复——**永远不钓上来**
- 斗笠不动；循环无缝

### 5.7 微交互参数总表

| 交互 | 参数 |
|---|---|
| 导航胶囊滑动 | 200ms，spring 弹性，胶囊**滑**到新位置（非淡入淡出） |
| 导航 hover | 背景底色浮现，150ms |
| 按钮 hover | 上浮 1px + 色深一档，150ms |
| 按钮按下 | 缩至 0.97，100ms |
| 页面切换 | **PCL2 式**：旧页淡出 120ms → 新页分组上浮 12px + 淡入 240ms ease-out，组间错落 40ms |
| 设备弹层展开 | 以设备圆钮为顶点 scale 展开，200ms `EasingOvershoot` |
| QR 弹层展开 | 以 QR 圆钮为顶点，同参数；鼠标移走即收，150ms 无过冲 |
| 弹层收起 | 150ms，scale 收回顶点 |
| 左栏拖拽 | 零延迟实时跟手；松手 100ms 吸附 |
| 设置页拨杆 | 200ms，滑块弹性到位 |
| QR 过期置灰 | 灰度 + 覆盖层淡入，300ms |
| 系统级 Toast | Windows 原生通知，不做自定义动画 |

## 附录 · 内核 v1.0（终稿）

> 墨堤是一座水墨的桥。声音从桥上过，小男孩在桥头等。
>
> 状态机是真相，动画是仪式，真相等仪式走完再登场。
> 一切变色皆有源头，一切移动皆有方向，一切等待皆有回应。
> 左栏会长出新的桥墩，设置页管着每一盏灯的开关。
> 墨堤不急——急吼吼的工具才抢 200ms，从容的软件先让水涨满。
